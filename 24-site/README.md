# 24 — site cozy Minecraft

Site statique en un seul fichier HTML (pas de build, pas de dépendances).

## Utiliser dans VS Code
1. Dézippe le dossier et ouvre-le dans VS Code (`code .`)
2. Ouvre `index.html`
3. Pour prévisualiser : clic droit sur le fichier → "Open with Live Server" (extension à installer), ou double-clique dessus pour l'ouvrir dans ton navigateur.
